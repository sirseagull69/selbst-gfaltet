## Was Claude Code ist

Claude Code ist Claude, aber nicht im Chatfenster, sondern in deinem Terminal, also dem schwarzen Fenster mit Textbefehlen. Der Unterschied: Claude Code kann direkt in deinem Ordner Dateien anlegen, ändern und Befehle ausführen. Du sagst, was du willst, und es baut.

Bevor es etwas Wichtiges tut, fragt es dich. Du behältst die Kontrolle.

Als Beispiel bauen wir einen **Pomodoro-Timer**: 25 Minuten arbeiten, 5 Minuten Pause, mit Ton am Ende. Klein, nützlich, in einer Stunde fertig. Genau so eine Seite war übrigens auch eine der Aufgaben im [Modell-Dreikampf](/blog/modell-dreikampf).

Der gute Auftrag sagt, **was** rauskommen soll, **wie** es aussehen soll, **was nicht** und **wer du bist**. Genau dafür gibt's auf diesem Blog den [Prompt-Baukasten](/werkzeuge#prompt): Felder ausfüllen, kopieren, bei Claude Code einfügen.

Ein paar Befehle, die du in Claude Code öfter brauchst: `/clear` fängt frisch an, `/compact` fasst ein langes Gespräch zusammen, `/help` zeigt alles. Mit `Esc` unterbrichst du, wenn Claude in die falsche Richtung läuft. Mehr auf dem [Spickzettel](/spickzettel).

## Was oft schiefgeht

<OriRand ori="ratlos" spruch="Zehn Wünsche auf einmal? Ich hab den dritten schon vergessen." />

- **Zu viele Wünsche auf einmal.** Lieber fünf kleine Runden als eine große. Sonst wird's unübersichtlich und du weißt nicht mehr, was was kaputt gemacht hat.
- **Nicht gesichert.** Ein Umbau geht schief, und die alte Version ist weg. Deshalb Git, früh.
- **Alles blind übernommen.** Wenn Claude Code fragt, ob es etwas löschen oder installieren darf: lesen, nicht einfach Ja drücken.
- **Riesiges Projekt als erstes.** Fang klein an. Erst der Timer, dann die App.
