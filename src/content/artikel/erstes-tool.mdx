## Erst der Chat, dann Claude Code

Viele denken, für das erste eigene Tool braucht man gleich Claude Code, ein Terminal und ein Abo. Braucht man nicht. Für ein kleines Werkzeug, das in einer einzigen Datei steckt, reicht der ganz normale Chat auf claude.ai, auch im kostenlosen Plan.

Du beschreibst, was du willst. Claude baut es direkt im Chat, du siehst es sofort und kannst es ausprobieren. Gefällt's dir, nimmst du es als Datei mit.

Claude Code kommt erst später ins Spiel, wenn aus dem kleinen Tool ein richtiges Projekt wird. Dazu unten mehr.

Als Beispiel bauen wir einen **Pomodoro-Timer**: 25 Minuten arbeiten, 5 Minuten Pause, mit Ton am Ende. Klein, nützlich, in einer halben Stunde fertig. Genau so eine Seite war übrigens auch eine der Aufgaben im [Modell-Dreikampf](/blog/modell-dreikampf).

## Der wichtigste Teil: dein Auftrag

<OriRand ori="sassy" spruch="„Mach mal was mit Timer.“ Und dann wundern." />

Hier entscheidet sich, ob du nach fünf Minuten was Brauchbares hast oder nach einer Stunde frustriert bist.

  <p slot="nachher">„Bau mir einen Pomodoro-Timer als eine einzige HTML-Datei, ohne Frameworks. 25 Minuten Arbeit, 5 Minuten Pause, Start- und Reset-Knopf, kurzer Ton am Ende. Der gute Auftrag sagt, **was** rauskommen soll, **wie** es aussehen soll, **was nicht** und **wer du bist**. Genau dafür gibt's auf diesem Blog den [Prompt-Baukasten](/werkzeuge#prompt): Felder ausfüllen, kopieren, bei Claude einfügen.

## Verstehen, was du da gebaut hast

<OriRand ori="liest" spruch="Ich hab's gebaut. Jetzt klick mal drauf." />

Das Tool läuft. Jetzt kommt der Teil, den die meisten überspringen: nachfragen. „Erklär mir die Funktion, die runterzählt.“ Oder: „Was passiert, wenn ich auf Reset drücke?“ Dafür musst du nicht programmieren können. Du lernst es so nebenbei.

Und heb dir die Dateien auf. Wenn du später was änderst, speicher die neue Version mit neuem Namen, zum Beispiel `pomodoro-2.html`. Dann hast du immer noch die alte, falls was schiefgeht.

## Wann sich Claude Code lohnt

<OriRand ori="vergleicht" spruch="Chat für den Zettel. Claude Code fürs Haus." />

Irgendwann wird's dem Chat zu eng. Spätestens dann lohnt sich Claude Code, also Claude im Terminal, direkt in einem Ordner auf deinem PC:

- **Mehr als eine Datei.** Das Tool hat eine Datenbank, mehrere Seiten oder ein paar Skripte dazu.
- **Du baust über Wochen dran.** Claude Code arbeitet direkt in deinem Ordner, du musst nichts mehr hin und her kopieren.
- **Du willst sichern und online stellen.** Mit Git jeden Stand speichern, mit Vercel kostenlos online stellen. Claude Code erledigt das gleich mit.

Dafür brauchst du dann ein Abo (Pro oder höher), im kostenlosen Plan ist Claude Code nicht dabei. Und du installierst es einmal:

Ein paar Befehle, die du in Claude Code öfter brauchst: `/clear` fängt frisch an, `/compact` fasst ein langes Gespräch zusammen, `/help` zeigt alles. Mit `Esc` unterbrichst du, wenn Claude in die falsche Richtung läuft. Mehr auf dem [Spickzettel](/spickzettel).

## Was oft schiefgeht

<OriRand ori="ratlos" spruch="Zehn Wünsche auf einmal? Ich hab den dritten schon vergessen." />

- **Zu viele Wünsche auf einmal.** Lieber fünf kleine Runden als eine große. Sonst wird's unübersichtlich und du weißt nicht mehr, was was kaputt gemacht hat.
- **Alte Version weg.** Ein Umbau geht schief, und die Datei, die lief, ist überschrieben. Deshalb jede funktionierende Version aufheben.
- **Zu früh zu groß.** Gleich Claude Code, Datenbank und Server, bevor das erste kleine Tool überhaupt steht. Fang im Chat an.
- **Alles blind übernommen.** Probier selbst aus, ob's wirklich tut, was es soll. „Fertig“ heißt nicht, dass es funktioniert.
