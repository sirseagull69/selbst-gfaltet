## Drei Werkzeuge fürs Netz

Ein Sprachmodell kann von sich aus gar nicht ins Internet. Es weiß nur, was es beim Training gelernt hat, und das ist irgendwann veraltet. Damit origami trotzdem aktuelle Sachen findet, hat sie drei Werkzeuge bekommen. Jedes ist wie eine Taste, die Gemma drücken kann.

Für die meisten Fragen reichen die ersten zwei. Den Browser braucht's erst, wenn man auf einer Seite wirklich was *tun* muss.

## Wie eine KI eine Webseite „sieht“

<OriRand ori="liest" spruch="Ich seh keine Seite. Ich seh eine nummerierte Liste." />

Hier wird's spannend. Gemma kann keine Bilder von Webseiten anschauen und dann irgendwo hinklicken wie du. Stattdessen bekommt sie eine Ansicht, in der jedes klickbare Element eine Nummer hat. Ungefähr so:

## Die Panne mit dem Formular

<OriRand ori="senden" spruch="Einmal abschicken ist Service. Zweimal ist Begeisterung." />

Beim Testen ist dann das passiert, wovor ich Angst hatte: origami hat ein Formular **zweimal abgeschickt**. Es war nur ein Testformular, aber stell dir vor, das wäre eine Bestellung gewesen.

## Wo Gemma beim Surfen schwächelt

<OriRand ori="websuche" spruch="Drei Grafikkarten. Eine Quelle. Reicht doch?" />

Ehrlich gesagt: Recherche über mehrere Seiten ist lokal die größte Schwäche. Im [Modell-Dreikampf](/blog/modell-dreikampf) hat Gemma für drei Grafikkarten nur eine einzige Quelle benutzt. Die anderen beiden Modelle haben bei der Aufgabe komplett versagt.

Das Problem ist das Einlesen. Jede Webseite ist ein langer Text, und lange Texte liest Gemma auf meinem PC langsam ein, weil sie nicht ganz in die Grafikkarte passt. Drei, vier Seiten hintereinander, und es dauert.

Deshalb macht origami das so:

- **Kurze Sachen bleiben lokal.** Eine Seite lesen, ein Formular ausfüllen, eine Suche.
- **Echte Recherche geht an Claude.** Wörter wie „vergleich“, „recherchier“ oder „mit Quellen“ schicken die Anfrage direkt in die Cloud. Probier's im Werkzeug [Lokal oder Claude?](/werkzeuge#route) aus.
- **Was oft gefragt wird, bekommt ein eigenes Werkzeug.** Wetter, Bahn, Fußball, Wikipedia, Währung: Dafür muss Gemma keine Webseite lesen, sondern drückt eine Taste und bekommt eine fertige kleine Antwort.

## Die versteckte Falle: Webseiten, die mit der KI reden

<OriRand ori="befund" spruch="Wenn eine Webseite mir Befehle gibt, ignorier ich sie. Aus Prinzip." />

Wer seine KI surfen lässt, muss eins wissen: Auf einer Webseite kann Text stehen, der sich als Befehl an die KI ausgibt. Unsichtbar für dich, lesbar für sie. Das nennt man Prompt-Injection.

Ich hab das getestet, mit einer eigenen Seite und einer versteckten Zeile drin. Seitdem prüft origami alles, was sie liest, auf solche eingeschleusten Befehle. Treffer werden mir gemeldet, nie ausgeführt.

So ein Check findet aber nur, was er kennt. Eine geschickt versteckte Anweisung kann durchrutschen. Der eigentliche Schutz ist deshalb die Absenden-Sperre: Selbst wenn origami auf eine Seite reinfällt, kann sie ohne mein Okay nichts abschicken, kaufen oder löschen. Später hab ich dasselbe mit präparierten Dateien und Mails probiert: [Ich hab meine eigene KI angegriffen](/blog/ori-und-die-schaedlinge).
